Enhancement Two: Algorithms & Data Structures CS 499

Artifact: CS 300 – ABCU Advising Assistant (C++)

This enhancement extends the original CS 300 advising assistant by modeling course prerequisites as a directed graph and implementing a depth-first search traversal algorithm to compute a full ordered prerequisite chain. The system detects cyclic dependencies and validates prerequisite integrity, improving correctness and robustness.

  • Hash Table: O(1) average-case lookup using std::unordered_map
  • Graph Representation: Adjacency list for prerequisite modeling
  • DFS Traversal: Computes ordered prerequisite chains
  • Cycle Detection: Prevents infinite recursion and validates data integrity
  • Performance: O(V + E) traversal complexity
